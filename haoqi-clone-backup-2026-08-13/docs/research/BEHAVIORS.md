# Behaviors

- Sayfa `html/body` scroll'u yerine `.lenis` sınıflı bağımsız dikey container kullanır.
- Ana sayfa masaüstünde yaklaşık 12.319 px, mobilde yaklaşık 11.301 px uzunluktadır.
- Header viewport'a sabitlenir ve içerik üzerinde kalır.
- Hero ve orta sahne WebGL canvas ile çizilir.
- 3B model ve sticker katmanları cursor/scroll hareketine tepki verir.
- Tema kontrolü `light`/`dark` kök sınıfını değiştirir.
- Ses kontrolü yerel `bgm.mp3` dosyasını kullanır.
- Proje kartlarında hover halinde medya/işaret durumları değişir.
- İç sayfa başlıkları hash anchor'larına bağlanır.
- İç sayfa görsellerinde büyütme/overlay etkileşimi vardır.
- `prefers-reduced-motion` durumunda CSS hareketleri azaltılır.
- Responsive kırılımlar: mobil 390 px, tablet 768 px, masaüstü 1440 px doğrulandı.
- Mobilde sayfa genişliği viewport ile aynı; yatay taşma yoktur.
