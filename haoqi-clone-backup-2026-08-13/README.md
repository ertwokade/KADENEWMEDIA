# Haoqi.design offline clone

Bu klasör, `https://haoqi.design/` sitesinin ana sayfasını ve siteden bağlı
altı iç sayfayı yerel dosyalarla çalıştırır.

## Çalıştırma

```bash
cd /Users/kadirdemir/Desktop/KADENEWMEDIA/haoqi-clone
npm run dev
```

Ardından aç:

`http://127.0.0.1:4180/`

## Kopyalanan rotalar

- `/`
- `/reunimos`
- `/inspire_mono`
- `/wasm_design_utils`
- `/adrive`
- `/shore_icon`
- `/teambition`

## İçerik

- Güncel HTML snapshot'ları
- Next.js CSS/JS runtime chunk'ları
- 3B `hello`, `cnt` ve imleç modelleri
- TikTok Sans, Geist Mono ve Departure Mono fontları
- Ana sayfa sticker'ları ve proje görselleri
- İç sayfa görselleri
- Özgün ve yerel kopya karşılaştırma ekranları

Kopya, `haoqi.design` runtime'ına bağlı değildir. Dış bağlantılar (Figma,
Twitter, GitHub, npm gibi) doğal olarak internete gider.

## Kade projesiyle ilişki

Klon ayrı tutuldu. Mevcut Kade ana sayfası ve React rotaları ezilmedi.
Kade iç sayfalarını bu tasarıma taşırken bu klasör görsel ve davranışsal
referans olarak kullanılabilir.
