# Accessibility Report

Durum: **BLOCKED_BY_ENVIRONMENT**

Bağlı in-app browser listesi boş olduğu için axe/Chromium taraması, keyboard/focus, contrast, zoom, touch target, modal focus trap, reduced-motion ve responsive overflow doğrulanamadı. Kaynak/raw HTML kontrollerinde public indexable sayfalara tek H1 ve temel nav fallback'i verildi; protected/noindex shell'ler public SEO kuralından ayrıldı.

Bu rapor axe sonucu iddia etmez. Release öncesi 169 manifestten public rotalar Chromium + axe ile; auth/dashboard kritik akışları authenticated fixture ile; 320, 360, 375, 390, 412, 768, 1024, 1280, 1440 ve 1920 genişliklerinde çalıştırılmalıdır.
